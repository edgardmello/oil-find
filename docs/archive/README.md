# Archived documentation

`README.zh-CN.md` preserves the former Chinese README for historical reference and the website's keyboard-reference tests. Its product, update and build instructions describe the upstream application, rather than this personal checkout. Use the root `README.md` and `AGENTS.md` for current local build instructions.

Untracked Finder clippings and previous installed Raycast binaries are archived separately under the ignored `.local-archive/` directory. Signing identities, user indexes and preferences are never part of build cleanup.
